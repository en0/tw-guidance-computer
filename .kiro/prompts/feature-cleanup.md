# Feature Cleanup

Identify features listed in the future ideas list that have already been captured or partially
captured as a tracked feature. For future ideas that are fully captured, remove them from the future
ideas list. For features that are partially captured, rewrite them to include only the details not
covered by existing tracked features.

- Future ides are stored in `docs/future-ideas.md`
- Tracked features are located in `.kiro/skills/tw-team/features/`
